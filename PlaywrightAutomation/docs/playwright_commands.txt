-> npx playwright test
#Runs the end-to-end tests.

-> npx playwright test --ui
#Starts the interactive UI mode.

->npx playwright test --project=chromium
#Runs the tests only on Desktop Chrome.

-> npx playwright test example
# Runs the tests in a specific file.

-> npx playwright test --debug
# Runs the tests in debug mode.

-> npx playwright codegen
# Auto generate tests with Codegen.

We suggest that you begin by typing:
-> npx playwright test

# execute test cases in headed mode (launch browser)
->  npx playwright test --headed

# command to show report
->  npx playwright show-report


# execute test cases with specific browser
->  npx playwright test --headed --project=chromium

# execute test cases by its name and filename
-> npx playwright test --grep "Flight booking test2" playwright_nested_test_suites.spec.ts

# command to execute test cases from commandline with AnnotationPractice
-> npx playwright test --grep "@sanity" AnnotationPractice.spec.ts --headed --project=chromium
