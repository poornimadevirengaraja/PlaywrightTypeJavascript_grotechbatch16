# 1. Install node js and verify on local system
->  npm -v
->  it will show latest version install on your system

# 2. Create a TypeScript Project directory e.g. TypeScriptPractice
->  Open integrated terminal in TypeScriptPractice
->  Then run below command in TypescriptPractice terminal only.

# 3. Initialize the project
-> npm init -y

# 4. Install Typescript Depedencies
-> npm install typescript --save-dev

# 5. Install typescript globally 
->  npm install -g typescript

# 6. verify typescript version
-> tsc -v
-> Version 7.0.2

# Initialize the typescript
-> npx tsc --init

# command to install ts node
-> npm install -D ts-node typescript @types/node

-> npm install -g ts-node typescript
